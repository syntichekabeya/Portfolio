Cisco Packet Tracer network project

Designed and configured a small enterprise-style network using a Cisco router, three Cisco switches, and six PCs across three subnets. Configured IP addressing and routing, tested communication between devices on different networks, and intentionally created a connectivity failure to practice troubleshooting. Identified and corrected the configuration issue, then verified restored connectivity using ping and Packet Tracer Simulation Mode.

  • Focus Network Configuration, Connectivity & Troubleshooting
  • Tools Cisco Packet Tracer, Cisco IOS CLI
  • Skills IP Addressing, Subnetting, Routing, Switching, Ping, Network Troubleshooting
